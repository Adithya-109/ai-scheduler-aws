# Benchmark results

Generated by `bench/run_benchmarks.py` (full mode, python 3.13.1, scikit-learn 1.9.1, 10 CPUs). The cloud node was not contacted: cloud times come from `hardware_benchmark.csv`.

## What the data says

* 495 scripts with measured edge and cloud times, RTT 110 ms.
* The cloud beat the edge (compute + RTT < edge) on **1 / 495** scripts; ignoring RTT it was faster on 373.
* Edge and cloud are similar machines here, so there is little to schedule. Real gains need a real asymmetry between nodes (docs/DEPLOY.md).
